# fluxer-rs (Archived / Unmaintained)

> [!WARNING]
> **This project is unmaintained.** This is the early-stage beginning of a Fluxer client/framework rewritten in Rust. I will not continue working on this repository. Feel free to fork it if you want to pick up where I left off.

A fast, async, and type-safe Rust framework for interacting with Fluxer instances, built with `tokio` and `reqwest`.

## ⚙️ Current State

This repository contains the foundational structure of the rewrite, including:
- Basic project setup (`Cargo.toml` configurations)
- Initial boilerplate for the async architecture
- Early API models / structures

## 📦 Usage & Local Setup

Since the project is incomplete, it is not published on crates.io. You can explore or build upon the source code locally using Cargo:

```bash
# Check the code / compilation
cargo check

# Run tests if any are present
cargo test
```
